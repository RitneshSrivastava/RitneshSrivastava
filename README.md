A production-shaped AI career preparation platform built with deep backend engineering depth.

| Feature | Implementation |
|---|---|
| **AI Resume Analysis** | Spring AI + OpenAI with structured JSON output parsing (not regex!) |

| **Authentication** | JWT stateless auth + BCrypt + Brevo HTTP OTP email (6-digit, 10min TTL) |
| **Job Matching** | Deterministic skill-intersection algorithm with explainable scores |
| **Deployment** | Dockerized Spring Boot backend on Render + managed PostgreSQL |
